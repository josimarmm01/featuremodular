# 📱 Projeto de Cadastro/Login - Android

## 🛠️ Tecnologias Utilizadas

- ✅ **Kotlin**
- 🎨 **Jetpack Compose** - UI declarativa
- 💉 **Koin** - Injeção de dependência
- 🔁 **Kotlin Flow** - Observação de estados
- 🧼 **Clean Architecture**
- 🧩 **Modularização por features**
- 📡 **UIState (sealed class)** - Controle de estados da UI

## 🔐 Funcionalidades

- Tela de **Splash** com redirecionamento automático.
- Tela de **Login** com validação de email e senha.
- Tela de **Cadastro** com validação dos campos e envio.
- Navegação entre telas com `NavController`.
- Estados da interface tratados com `UIState` (Loading, Success, Error).
